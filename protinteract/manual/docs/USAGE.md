# JSON 생성 사용 안내

## 입력부터 다운로드까지

1. 타겟 구성에 한 줄당 `UniProt ID 복제수`를 입력합니다. 생략한 복제수는 1입니다.
2. 후보 ID는 줄바꿈·쉼표·공백·세미콜론으로 구분합니다.
3. 타겟 이름을 선택 입력하고 5,000 이하의 토큰 한도를 설정합니다.
4. 미리보기를 만들고 ID·생물종·전체 서열·복제수·제외 사유를 확인합니다.
5. JSON을 내려받아 AlphaFold Server에 직접 임포트합니다.

## 테스트 예시

타겟: `P04637 1`

후보:

```text
Q00987
P04637-2
BAD
```

정상 후보는 포함하고 `BAD`는 형식 오류로 제외해야 합니다. 같은 타겟을 후보로 넣으면 기존 복제수에 후보 1개를 더한 수량을 안내합니다. 입력을 바꾼 후에는 미리보기를 다시 생성해야 합니다.

## 입력 조건

- 한 요청의 타겟·후보는 각각 최대 100개입니다.
- 표준 아미노산 20종만 허용하며 체인당 최소 4잔기입니다.
- 토큰 수는 단백질 서열 길이 × 복제수의 합이며 최대 5,000입니다.
- isoform 응답이 요청과 다르면 제외하며 canonical 서열로 대체하지 않습니다.
- 서열은 자동 절단·치환하지 않습니다.

형식과 한도 확인일: 2026-10-18. [공식 JSON 문서](https://github.com/google-deepmind/alphafold/tree/main/server), [AlphaFold Server](https://alphafoldserver.com/).

## 캐시와 오류

‘저장된 조회 결과 사용’을 끄면 새로 조회합니다. 자동 만료는 없습니다. 캐시는 설치된 패키지 아래 `data/cache/uniprot`에 저장하며, 저장 권한이 없어도 조회·생성은 동작합니다. 읽을 때 검증하고 불완전한 캐시는 재조회합니다.

타겟 오류는 전체 생성을 중단하고 후보 오류는 해당 후보만 제외합니다. 통신 오류가 있으면 연결 상태와 인증서 설정을 확인하세요. 원본 조회와 다운로드 서열은 같은 결과를 사용합니다.

## API

```json
{
  "target_text": "P04637 1",
  "candidate_text": "Q00987 P04637-2",
  "target_label": "test",
  "token_limit": 5000,
  "use_cache": true
}
```

위 요청을 `POST /api/v1/jobs/preview`로 보내면 `jobs`에 완전한 JSON이 반환됩니다. `preview` 필드만 축약되어 있습니다. 조회는 `POST /api/v1/proteins/lookup`에 `{"ids":"P04637","use_cache":true}`를 보냅니다.
